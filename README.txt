Open index.html in a modern browser. Upload an image, move the near-complete 3x3 puzzle,
see a randomized reward selection, enter an ID, and see the final confirmation screen.
The reward amounts are demo display values only. This static app does not connect to eFootball
or send rewards to an account. The ID field is not transmitted anywhere.
